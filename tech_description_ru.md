# Технологии и библиотеки в RAG-системе

## data_processing.py

### Основные библиотеки

#### langchain
**Описание**: LangChain — современный фреймворк для разработки приложений с использованием языковых моделей (LLM). Он обеспечивает абстракции для работы с различными компонентами, необходимыми для создания RAG-систем.

**Применение в проекте**: Используется для загрузки документов, разбиения текста на чанки, создания векторных представлений и организации процесса извлечения информации. Интегрирован с LangGraph для создания сложных рабочих процессов.

#### langchain_community
**Описание**: Модуль LangChain, содержащий интеграции с внешними сервисами, базами данных и моделями, поддерживаемыми сообществом.

**Применение в проекте**:
- `DirectoryLoader` — для загрузки всех документов из указанной директории
- `UnstructuredHTMLLoader` — для загрузки и обработки HTML-документов
- `PyPDFLoader` — для загрузки и извлечения текста из PDF-документов
- `UnstructuredWordDocumentLoader` — для работы с документами Word
- `TextLoader` — для обработки текстовых файлов
- `Qdrant` — для интеграции с векторной базой данных Qdrant

#### langchain_core
**Описание**: Ядро фреймворка LangChain, содержащее базовые абстракции и интерфейсы.

**Применение в проекте**:
- `Document` — класс для представления документов с текстом и метаданными
- `Embeddings` — абстрактный интерфейс для создания векторных представлений текста

#### langchain_text_splitters
**Описание**: Модуль для разбиения длинных текстов на меньшие фрагменты для обработки языковыми моделями.

**Применение в проекте**: `RecursiveCharacterTextSplitter` используется для разбиения документов на смысловые фрагменты заданной длины с учетом естественных границ текста.

#### langsmith
**Описание**: LangSmith — платформа для отладки, тестирования и мониторинга LLM-приложений.

**Применение в проекте**:
- `traceable` — декоратор для отслеживания функций и их производительности
- `trace` — контекстный менеджер для отслеживания выполнения блоков кода
- Используется для мониторинга выполнения RAG-процессов и отладки

#### Qdrant
**Описание**: Векторная база данных для эффективного хранения и поиска по высокоразмерным векторам.

**Применение в проекте**:
- `QdrantClient` — клиент для взаимодействия с Qdrant
- Используется для хранения векторных представлений документов и поиска похожих документов

#### numpy
**Описание**: Библиотека для научных вычислений, работы с многомерными массивами и матрицами.

**Применение в проекте**: Используется для операций с векторами при создании эмбеддингов и обработке результатов поиска.

#### scikit-learn
**Описание**: Библиотека машинного обучения для Python, содержащая алгоритмы классификации, регрессии, кластеризации и обработки данных.

**Применение в проекте**: Используется TfidfVectorizer для создания TF-IDF векторных представлений в SimpleEmbeddings.

#### sentence-transformers
**Описание**: Библиотека для создания векторных представлений предложений и текстов с использованием предобученных трансформерных моделей.

**Применение в проекте**: Используется для создания качественных семантических эмбеддингов в RoSBERTaEmbeddings.

#### torch & transformers
**Описание**: PyTorch и Hugging Face Transformers для работы с нейронными сетями и предобученными моделями.

**Применение в проекте**: Обеспечивают работу с трансформерными моделями для создания эмбеддингов.

#### SimpleEmbeddings
**Описание**: Кастомный класс для создания векторных представлений текста с использованием TF-IDF и нормализации размерности.

**Применение в проекте**: 
- Создает векторные представления документов для поиска по семантическому сходству в Qdrant
- Автоматически нормализует размерность векторов до 1024 измерений
- Обеспечивает совместимость с требованиями Qdrant по фиксированной размерности

#### RoSBERTaEmbeddings
**Описание**: Класс для создания векторных представлений с использованием предобученной модели RuBERT/RoSBERTa.

**Применение в проекте**:
- Создает более качественные семантические векторы для русскоязычных текстов
- Интегрирован с Hugging Face Transformers через sentence-transformers
- Обеспечивает лучшее понимание контекста и семантики русского языка

## rag_app.py

### Основные библиотеки

#### gradio
**Описание**: Фреймворк для создания веб-интерфейсов для моделей машинного обучения.

**Применение в проекте**: Используется для создания интерактивного чат-интерфейса для взаимодействия с RAG-системой.

#### langchain_community.llms
**Описание**: Модуль для работы с различными языковыми моделями через единый интерфейс.

**Применение в проекте**: `LlamaCpp` используется для работы с локальными GGUF-моделями, обеспечивая приватность данных и автономную работу.

#### llama-cpp-python
**Описание**: Python-биндинги для llama.cpp, позволяющие запускать модели LLaMA локально.

**Применение в проекте**: Обеспечивает работу с локальными GGUF-моделями через LlamaCpp.

#### langgraph
**Описание**: Библиотека для создания направленных ациклических графов (DAG) для оркестрации сложных процессов с использованием LLM.

**Применение в проекте**:
- `StateGraph` — для создания структурированного рабочего процесса RAG с четко определенными шагами
- `MemorySaver` — для сохранения состояния между запросами
- Организует процесс извлечения документов, их обработки и генерации ответов

#### langchain.retrievers
**Описание**: Модули для извлечения релевантных документов из хранилища.

**Применение в проекте**:
- `BM25Retriever` — для поиска документов на основе алгоритма BM25 (статистический метод поиска)
- `EnsembleRetriever` — для комбинирования результатов нескольких ретриверов (семантического и статистического)

#### rank_bm25
**Описание**: Реализация алгоритма BM25 для статистического поиска по тексту.

**Применение в проекте**: Используется в BM25Retriever для лексического поиска документов по ключевым словам.

#### langsmith
**Описание**: Платформа для мониторинга, отладки и улучшения LLM-приложений.

**Применение в проекте**:
- `Client` — для взаимодействия с API LangSmith
- `trace` — для трассировки выполнения функций и отслеживания производительности
- Важно: используется внутри функций через контекстный менеджер `with trace(name="function_name"):` вместо декораторов для совместимости с LangGraph

#### HybridSearch
**Описание**: Кастомный класс для реализации гибридного поиска.

**Применение в проекте**:
- Комбинирует векторный (семантический) и BM25 (статистический) поиск
- Обрабатывает документы с различной структурой полей (`text` и `page_content`)
- Включает механизм отката к прямому поиску в Qdrant в случае сбоев

#### RAGAssistant
**Описание**: Основной класс, реализующий RAG-систему с использованием LangGraph и мультиагентной архитектуры.

**Применение в проекте**:
- Создает и управляет графом рабочего процесса с использованием StateGraph
- Определяет шаги обработки: извлечение документов, генерация ответов, работа с инструментами
- Обеспечивает взаимодействие между компонентами системы
- Поддерживает различные типы агентов (RAG, SQL, визуализация)
- Интегрирует Oracle Text2SQL для работы с базами данных
- Включает систему инструментов для расширения функциональности

#### LangChainAssistant
**Описание**: Класс для работы с языковой моделью через LangChain.

**Применение в проекте**:
- Загружает и инициализирует модели
- Форматирует запросы и ответы
- Обрабатывает историю сообщений

### Дополнительные компоненты

#### OracleText2SQL
**Описание**: Модуль для преобразования естественного языка в SQL-запросы для работы с базами данных Oracle.

**Применение в проекте**: Обеспечивает возможность выполнения SQL-запросов к базе данных на основе пользовательских запросов на естественном языке.

#### Memory Storage
**Описание**: Система управления памятью для сохранения контекста диалога и истории взаимодействий.

**Применение в проекте**: Обеспечивает персистентность данных между сессиями и улучшает качество ответов за счет учета предыдущих взаимодействий.

#### Text Utils
**Описание**: Утилиты для обработки и форматирования текста.

**Применение в проекте**: Форматирование результатов поиска, обработка источников, подготовка текста для отображения.

### Особенности реализации

1. **Мультиагентная архитектура**:
   - Система использует несколько специализированных агентов для разных типов задач
   - Роутер-агент определяет, какой агент должен обработать запрос
   - Поддержка RAG-агента, SQL-агента и агента визуализации

2. **Поддержка различных форматов документов**:
   - Система работает с документами, имеющими поля `text` или `page_content`
   - Автоматически определяет формат и извлекает необходимую информацию
   - Поддержка PDF, HTML, DOCX, TXT файлов

3. **Трассировка с LangSmith**:
   - Вместо декораторов `@trace` используются контекстные менеджеры `with trace(name="..."): `
   - Обеспечивает совместимость с LangGraph, который ожидает функции, а не объекты трассировки
   - Детальное отслеживание выполнения всех этапов обработки

4. **Обработка размерности векторов**:
   - Автоматическое дополнение или усечение векторов до 1024 размерности
   - Предотвращает ошибки несоответствия размерности в Qdrant
   - Поддержка различных типов эмбеддингов (TF-IDF, BERT-based)

5. **Гибридный поиск**:
   - Комбинирует семантический поиск (по векторам) и статистический (BM25)
   - Резервный механизм прямого поиска в Qdrant при сбоях
   - Настраиваемые веса для различных типов поиска

6. **Интеграция с базами данных**:
   - Поддержка Oracle Database через oracledb
   - Возможность выполнения SQL-запросов на естественном языке
   - Безопасная обработка подключений к БД

7. **Система инструментов**:
   - Расширяемая архитектура инструментов для различных задач
   - Поддержка визуализации графа системы
   - Интеграция с внешними API и сервисами
